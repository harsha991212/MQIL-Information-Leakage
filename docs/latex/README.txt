MQIL Project Report — Overleaf LaTeX source

How to use:
1. Open https://www.overleaf.com/
2. Create a Blank Project (or choose Upload Project).
3. Upload this ZIP file.
4. Open main.tex and select it as the Main document if Overleaf does not do so automatically.
5. Set Compiler to pdfLaTeX (Menu -> Settings -> Compiler).
6. Click Recompile.

Notes:
- The report text is converted from the supplied DOCX report into an editable LaTeX report.
- The generator LOC range was updated to 1,900–2,100 based on the latest local validation (minimum 1,900, maximum 2,100).
- If you changed/regenerated the C dataset after the feature extractor was last run, rerun the feature extractor and refresh the feature CSV results before final submission.
- Review institute/department formatting requirements, names, dates, signatures, references, and all reported experimental values with your supervisor before submission.
